# วรรคจากหนังสือ (ใบงาน v3/pleng#105)

หน้าฝึกร้องและแผ่นเพลงเขียนเนื้อล้วนได้ 3 แบบ แบบที่ 3 คือ **ตามต้นฉบับ** — เว้นวรรคตรงที่
**หนังสือเพลงเล่มจริงเว้นไว้** เครื่องมือในโฟลเดอร์นี้คือตัวที่ไปอ่านหนังสือมาให้ รันซ้ำได้ทุกเมื่อ

## กติกาที่ห้ามละเมิด

- **อ่านไฟล์หนังสืออย่างเดียว** ไม่เขียนอะไรกลับลงไฟล์หนังสือ
- **ไม่แตะเนื้อเพลงในคลังเด็ดขาด** เครื่องมือนี้อ่านคลังอย่างเดียว เอามาแค่ **ตำแหน่งที่เว้นวรรค**
  คำทั้งหมดยังเป็นของคลังเหมือนเดิม (คลังถูกแก้มาอย่างตั้งใจ และหนังสือเองก็ผิดได้)
- **ท่อนที่เนื้อต่างจากหนังสือมาก ไม่เดา** ข้ามแล้วใส่ไว้ในรายงานให้คนมาเติม

## เอาอะไรมาจากหน้าไหน

หนังสือพิมพ์เนื้อไว้ 2 ที่ **ใต้บรรทัดโน้ต** กับ **ข้อที่เป็นตัวหนังสือล้วน** (ข้อ 2 ข้อ 3 …)

ที่ใช้ได้คือ **ข้อที่เป็นตัวหนังสือล้วน** เท่านั้น เพราะเนื้อที่อยู่ใต้โน้ตถูกจัดช่องไฟให้ตรงกับตัวโน้ต
ข้างบน ช่องว่างตรงนั้นจึงไม่ได้แปลว่าแบ่งวรรค ส่วนข้อที่เป็นตัวหนังสือล้วนเรียงมาเพื่อให้คนอ่าน
**ช่องว่างตั้งแต่ 2 ช่องขึ้นไป = รอยแบ่งวรรค**

ท่อนที่ร้องด้วยทำนองเดียวกันจะหายใจที่เดิม เครื่องมือจึง **ยกวรรคของทำนองหนึ่งไปให้ท่อนอื่นที่ใช้
ทำนองเดียวกัน** โดยอิงตำแหน่งตัวโน้ต (ท่อนที่ได้มาแบบนี้ขึ้นว่า `melody` ในรายงาน) และจะไม่ยกไป
ถ้ามันไปผ่ากลางคำ ถ้าไม่อยากได้ส่วนนี้ ใส่ `--no-melody`

## วิธีรัน

```bash
# 1) อ่านไฟล์หนังสือ -> ข้อความที่มีรอยแบ่งวรรค
python tools/bookPhrases/extract_book_text.py "<ที่อยู่ไฟล์หนังสือ>.pdf" \
       -o tools/bookPhrases/book-anuchon.json

# 2) ดึงเพลงจากคลัง (อ่านอย่างเดียว) ลงไฟล์ชั่วคราว
curl -H "apikey: <คีย์อ่านอย่างเดียว>" -H "Authorization: Bearer <คีย์อ่านอย่างเดียว>" \
  "https://<คลัง>.supabase.co/rest/v1/songs?select=number,title_th,category,content&category=eq.anuchon&deleted_at=is.null" \
  -o tmp/anuchon.json

# 3) ทาบหนังสือกับคลัง -> ไฟล์ข้อมูลที่เว็บอ่าน + รายงานตัวเลข
node tools/bookPhrases/build.mjs --book-text tools/bookPhrases/book-anuchon.json \
     --songs tmp/anuchon.json --out src/data/bookPhrases.anuchon.json \
     --report tools/bookPhrases/report-anuchon.json
```

ต้องมี `pypdf` (ขั้นที่ 1) และ Node (ขั้นที่ 3)

## ภาพเทียบหนังสือกับจอ

```bash
npm run dev -- --port 5199
node tools/bookPhrases/shots.mjs --port 5199 --out tmp/shots --ids tmp/shot-ids.json
python tools/bookPhrases/compose_shots.py "<ที่อยู่ไฟล์หนังสือ>.pdf" --ids tmp/shot-ids.json \
       --shots tmp/shots --book-text tools/bookPhrases/book-anuchon.json \
       --out docs/backlog-assets/B105-book-phrase
```

`shots.mjs` ต้องมี `playwright-core` (`npm i playwright-core --no-save`) และใช้ Microsoft Edge
ที่เครื่องมีอยู่แล้ว ส่วน `compose_shots.py` ต้องมี `pymupdf` กับ `pillow`
ทั้งสองตัวใช้ตอนตรวจงานเท่านั้น ไม่ใช่ของที่เว็บต้องใช้

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | คืออะไร |
| --- | --- |
| `extract_book_text.py` | ขั้นที่ 1 อ่านไฟล์หนังสือ |
| `book-anuchon.json` | ผลของขั้นที่ 1 (ข้อความจากหนังสือ แบ่งวรรคไว้แล้ว) |
| `build.mjs` | ขั้นที่ 2 ทาบกับคลัง แล้วเขียน `src/data/bookPhrases.anuchon.json` |
| `report-anuchon.json` | รายงาน ได้กี่เพลง กี่ท่อน และเพลงไหนที่คนต้องมาเติมเอง |
| `shots.mjs`, `compose_shots.py` | ทำภาพเทียบหนังสือกับจอ |
