## ✅ ดีไซน์ของ P'Aim ตรงกับคนที่อัดเชลโลตัวนี้เป๊ะ

P'Aim: *"mp mf สั้น ๆ มากๆ แล้วลากด้วย p · การแสบน่าจะเกิดตอนช่วงแรกของการเริ่มสีขึ้นหรือลง"*

readme ของ Karoryfer เขียนเอง: **"staccato attacks layered on top of sustained notes"**
`vc_arco_marcato_map.sfz` → **`ampeg_hold=0.200`** (หัว 200ms) + **`ampeg_sustain_oncc103=0`** (หัวหลบออกไป
ให้ตัวโน้ตพาต่อ) + **`amplitude_oncc110=100`** = **ปุ่มปรับความแรงหัวโน้ต**

→ **แม้แต่ "ความแรงหัวโน้ตต้องเป็นปุ่ม ไม่ใช่ค่าตายตัว" คนอัดเขาก็คิดแบบเดียวกัน** — ผมทำตามทั้งดีไซน์และค่า
(hold 200ms · หัวไม่ค้าง · ความแรงเป็นปุ่ม)

**และนี่ไม่ใช่ "ผสม 2 ชั้น" ที่เรากลัว** — หัวกับตัวโน้ต **แยกกันด้วยเวลา** (หัวมา 200ms แรกแล้วหลบ)
ไม่ใช่ crossfade เบา↔แรง ของโน้ตเดียวกันค้างคู่กันทั้งตัว (อันนั้นคือที่ฟังเป็น "เชลโล 2 ตัว") — **PM แก้คำพูดถูกแล้ว**

## 🔬 สมมติฐาน PM ที่ต้องให้หูทดสอบ (ผมยังตอบไม่ได้)

> "หัวโน้ตคมเคาะตรงบีต → หูยึดหัวเป็นตัวบอกจังหวะ → `p` บวมช้าข้างล่างได้โดยไม่รู้สึกช้า → ไม่ต้องเลื่อน `p` เลย"

**วัดได้แค่ว่ามันเป็นไปได้:** หัวโน้ต `mf` ไต่ **20 ms** · `mp` ไต่ **55 ms** vs ตัว `p` ไต่ **200 ms**
→ **หัวมาถึงหูก่อนตัวโน้ต 145–180 ms** = มีของให้หูยึดตรงบีตจริง
**แต่ "หูจะยึดหัวแล้วปล่อยตัวช้าได้ไหม" ผมพิสูจน์ไม่ได้** → **นี่คือเหตุผลที่ปุ่ม "เลื่อนเวลาตัวโน้ต" ต้องหมุนได้**
ถ้า P'Aim ตั้ง 0 แล้วยังไม่รู้สึกช้า = **PM ถูก และไอเดียเดียวของ P'Aim แก้ได้ 3 เรื่องพร้อมกัน** (ขาดมิติ · แสบ · เร่ง)

## ⚠️ กับดักที่เลี่ยงแล้ว

PM เตือน: **อย่าทำ "ดัง = ชั้นแรง" ตรง ๆ** เพราะโน้ตที่ P'Aim ว่า "หนัก" คือโน้ตที่ระบบสั่งดัง → แมปตรง ๆ จะไปหยิบ `f`
(สว่างสุด = แสบสุด) = ทำโน้ตที่เขาไม่ชอบให้แย่ลง
→ **ผมไม่ได้ทำ layer-selection ตามความดังเลย** · ตัวโน้ต = `p` เสมอ · หัวโน้ต = ชั้นเดียวคงที่ ความแรงเป็นปุ่มรวม
**หัวแยกจากตัว = เลี่ยงกับดักนี้พอดีตามที่ PM ว่า**

## ตรวจแล้ว (วัด ไม่ใช่เชื่อ)

- ✅ **เปียโนเหมือนกันเป๊ะทั้ง 3 คลิป** (3×10⁻⁸ = ปัดเศษ float32)
- ✅ **ตัวโน้ต (`p`) เหมือนกันเป๊ะทั้ง 3 คลิป** เมื่อปิดหัว (1×10⁻⁸) → **ต่างกันแค่หัวโน้ตจริง ๆ**
- ✅ **ปิดหัวโน้ต (0%) = เหมือน "p ล้วน" ทุกบิต** (ต่าง <10⁻⁶) → ปุ่มนี้เป็นตัวแปรเดียวจริง
- ✅ **ทั้ง 2 ปุ่มเปลี่ยนเสียงจริง** (ไม่ใช่ปุ่มหลอก) · ค่าที่รายงานตรงกับที่ตั้ง (0 → 0ms · 200 → 200ms)
- ✅ ไม่มีคลิป (peak สูงสุด −3.0 dB) — หัวโน้ตทำให้ peak สูงขึ้นจาก −8 เป็น −3 **ซึ่งถูกต้อง** (marcato = transient)
- ✅ ทุกคลิป RMS −24.0 dB เท่ากัน · 20.3s เท่ากัน · ไม่มีโน้ตนอกช่วงเชลโล
- ✅ deterministic · ไม่แตะ `dynamics.js` · ไม่แตะโค้ด deploy · ไม่มีไฟล์เสียงใน git
- ❌ **"เพราะขึ้นไหม / แรงเท่าไหร่พอดี" ผมตอบไม่ได้** → หู P'Aim

## 🔴 เจอบั๊กอีกตัวระหว่างทำ — คลาสเดียวกับ "เสียงบอด"

(ไม่ปล่อยให้เงียบ ๆ แล้วไปโผล่ที่หูของ P'Aim)
