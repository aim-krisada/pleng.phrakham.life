# วิเคราะห์ 2 เพลงอ้างอิง (เปียโน+เชลโล) — ถอดเทคนิคที่ลอกได้

สายงาน: analysis อย่างเดียว · ไม่แตะ `src/lib/arranger/` · brief = `docs/pm/brief-reference-analysis.md` v2

## สรุปสั้นสุด (ถ้าอ่านแค่ย่อหน้าเดียว)

**ผลวัดค้าน 2 ข้อใหญ่ที่เราเชื่อกันอยู่ (ทั้งของที่ปรึกษาและของ brief เอง):**

1. **เปียโนไม่ได้ "หลบ" เชลโล — มันดัง+รัวขึ้น *พร้อมกัน*** ตอนเชลโลร้องนำ เปียโนดังขึ้น **+4.1 dB (Canon) / +6.1 dB (ATY)** และเล่นโน้ตถี่ขึ้น **+12% / +83%** · ค่า correlation เป็นบวกทั้งคู่ → **"ลมหายใจร่วม" = สวดขึ้นด้วยกัน ไม่ใช่คนหนึ่งหรี่ให้อีกคน**
2. **เชลโลในทั้ง 2 เพลง "ร้องนำ" ไม่ได้ "เดินเบส"** — median **B3 (248Hz) / A♯3 (232Hz)** = ย่านเสียงร้อง (tenor) ทั้งคู่ · **นี่ค้าน brief §(ง) ที่ว่า Canon = เชลโลเดินเบส** และน่าจะอธิบายว่าทำไมเชลโลเราพัง: **เราเอาเชลโลไปเดินเบส = ผิดหน้าที่ตั้งแต่แรก** (memory: bass+swell = "หวูดเรือ")

**ของที่คุ้มสุดที่ควรแก้ = arc ทั้งเพลง:** ของจริงกวาด **13.4 / 15.1 dB** จากเบาสุดถึงไคลแมกซ์ · `sectionDynamics` ของเรากวาดแค่ **1.41 dB** = **แบนกว่าของจริง ~10 เท่า**

## วิธีวัด + ขีดจำกัด (อ่านก่อนเชื่อตัวเลข)

- **Claude ฟังเสียงไม่ได้** — ทุกบรรทัดข้างล่างมาจากเครื่องมือวัด ไม่มี "ฟังแล้วรู้สึกว่า..." สักคำ · ข้อไหนวัดไม่ได้ เขียนว่าวัดไม่ได้
- แยกเสียง: **demucs `htdemucs_6s`** → ใช้ stem `piano` (เปียโน) + `other` (เชลโล) · stem `bass`/`drums`/`guitar` เงียบจริง (peak −54/−63/−37 dB) = ยืนยันว่าเป็นดูโอ 2 ชิ้นจริง แยกสะอาด
- วิเคราะห์ในเครื่องเท่านั้น · **ไม่ commit MP3/stem** · ไม่มี transcription โน้ต · เอาเฉพาะ**สถิติเชิงเทคนิค** (dB, โน้ต/วินาที, ms)
- ⚠️ **stem มี artifact เสมอ** → **ตัวเลขทุกตัว = ค่าประมาณ** ปัดทศนิยม 1 ตำแหน่ง อย่าอ่านเป็นความจริงสัมบูรณ์
  - Canon stem เชลโลสะอาด (นอกช่วงเชลโล 2.7% ล่าง / 2.9% บน)
  - **ATY stem เชลโลมีเบสเปียโนรั่ว 10.8%** (ต่ำกว่าสาย C2 = เชลโลเล่นไม่ได้) → ตัวเลขย่านต่ำของ ATY เชื่อได้น้อยกว่า
- **n = 2 · ไม่เฉลี่ยรวม** — รายงานแยกทีละเพลง แล้วค่อยสรุปว่าอะไรตรงกัน (น่าเชื่อ) / ต่างกัน (ขึ้นกับบทเพลง)

## ตรวจ 4 ข้อที่ PM ค้านที่ปรึกษาไว้ — ผลวัดว่ายังไง

| ข้อ | PM ว่าไว้ | ผลวัดบอกว่า |
|---|---|---|
| **1. ต้องวัดทั้ง dB และความหนาแน่น** | ✅ **PM ถูก และสำคัญกว่าที่คิด** | ถ้าดู dB อย่างเดียวจะพลาดทั้งเรื่อง: ATY ความหนาแน่นขยับ **+83%** ขณะ dB ขยับ 6.1 dB · **แต่ทิศทางกลับด้าน** — ไม่ใช่ "หรี่+ลดรัว" แต่เป็น **"ดัง+รัวขึ้นพร้อมกัน"** |
| **2. เปลี่ยน "ตัดเบส <200Hz" → voicing** | ✅ **PM ถูก** (แต่ด้วยเหตุผลที่ลึกกว่า) | **ไม่มีเพลงไหนตัดเบสเลย** (Canon 22.2 vs 19.9% · ATY เติมเบสด้วยซ้ำ) · การไม่ชนกันมาจาก **เชลโลถูกวางไว้ในย่านร้อง (B3) เหนือเบสเปียโน** = แยกด้วยการเรียบเรียง ไม่ใช่การหรี่ |
| **3. ค้าน "หน่วงแบบสุ่ม"** | ✅ **PM ถูก — และแรงกว่านั้น** | วัดแล้ว **SD 57–64 ms · mean ≈ 0 · อยู่ใน ±20ms แค่ 21–27%** → **ไม่มีหลักฐานว่ามีการเหลื่อมที่มีทิศทางเลย** · ไม่ใช่แค่ "ห้ามสุ่ม" แต่ **ไม่มีข้อมูลรองรับให้ใส่ offset อะไรทั้งนั้น** |
| **4. ค้าน "ผลลัพธ์เป็น if-else"** | ✅ **PM ถูก และผลวัดอธิบายว่าทำไม** | ข้อ (7): เชลโลเล่น **82–93%** ของเวลา = **ไม่มีการผลัดกันเล่นให้ลอกเลย** → กฎ `ถ้าเปียโนหยุด → เชลโลเข้า` **ไม่ตรงกับของจริงตั้งแต่ต้น** · สิ่งที่คุมของจริงคือ **ระดับความเข้มต่อท่อน** (ทั้งคู่ขึ้น-ลงพร้อมกัน) = phrase-level plan จริง ๆ |
| **5. n=2 ห้ามเฉลี่ย** | ✅ **PM ถูก** | ความหนาแน่น +11.8% vs +82.7% = **ต่างกัน 7 เท่า** · เฉลี่ยได้ ~47% = ไม่เหมือนสักเพลง |

### ❗ ข้อที่ผลวัด **ค้าน brief เอง**

**brief §(ง) เขียนว่า "Canon = เชลโลเดินเบสตลอด (ground bass)"** — **ผลวัดบอกว่าไม่ใช่:**
- เชลโล Canon median **B3 (248Hz)** · p25–p75 = F♯3–E4 · ต่ำกว่าสาย C2 แค่ 2.7% → **ร้องนำในย่าน tenor**
- คนเดินเบสคือ **เปียโน** (<120Hz: เปียโน 10.5% vs เชลโล 2.6% = 4 เท่า)
- **`board.md` บรรทัด 117 เขียนถูก** ("เชลโลเดินทำนอง + เปียโน ground bass/arpeggio") — brief §(ง) ขัดกับ board เอง

**ทำไมข้อนี้สำคัญที่สุดในรายงาน:** §(ง) วางกรอบว่า 2 เพลงนี้ "สอนคนละเรื่อง" (เดินเบส vs ร้องนำ) · **ผลวัดบอกว่าทั้งคู่สอนเรื่องเดียวกัน: เชลโลร้องนำในย่าน tenor** → ข้อสรุป 10 ข้อในตาราง "ตรงกันทั้งคู่" จึงน่าเชื่อกว่าที่ brief คาด · และมันชี้ root cause ใหม่: **เชลโลเราพังส่วนหนึ่งเพราะถูกส่งไปเดินเบส ซึ่งของอ้างอิงไม่มีใครทำ**

⚠️ **ต้องให้ P'Aim ฟันธงด้วยหู:** ผมฟังไม่ได้ · ข้อนี้อิง stem + pitch tracker · **P'Aim ฟังแล้วยืนยันได้ไหมว่า Canon = เชลโลสีทำนอง เปียโนเดินเบส?** (ถ้าใช่ = ปิดเคส)

### กอง (ค) — ทำไม่ได้ด้วย sample ฟรี (ยอมรับเพดาน)

| เรื่อง | ทำไม |

| **"เพราะ/เข้ากัน"** | วัดไม่ได้เลย · เครื่องมือพิสูจน์ได้แค่ "มีเสียง/ไม่คลิป/พิตช์ถูก" ([[pleng-aesthetic-audio-needs-ear]]) |

## สิ่งที่ **วัดไม่ได้** — ต้องให้ P'Aim ฟันธง

1. **เหลื่อมเวลาเชลโล-เปียโน** — SD **57–64 ms** กว้างเกินจะสรุปทิศทาง · mean ≈ 0 · ใน ±20ms แค่ 21–27% → **ตัวจับ onset น่าจะจับคนละโน้ตมาจับคู่กัน** · **ข้อสรุป: ไม่มีหลักฐานให้ใส่ค่าหน่วงใด ๆ** (ทั้งสุ่มและไม่สุ่ม) → `humanizeTime` sigma 12ms ปัจจุบัน **ไม่มีหลักฐานอ้างอิงมาสนับสนุนหรือค้าน** ปล่อยไว้ก่อน
2. **rubato / การยืดท้ายวรรค** — BPM SD = 4.1% (Canon) / 3.6% (ATY) · **แต่แยกไม่ออกจาก error ของตัวจับบีตเอง** → **สรุปไม่ได้ว่ายืดจริงกี่ %** · `RUBATO_STRETCH = 1.12` ปัจจุบันไม่มีหลักฐานมายืนยัน · (Canon tempo ที่ตรวจได้ = 148–152 BPM น่าจะเป็นการนับ**ครึ่งบีต** → ของจริงราว 74–76 BPM · ยิ่งยืนยันว่าตัวจับบีตไม่น่าเชื่อในเพลงนี้)
3. **หางเสียง / reverb / pedal ring** — วัดได้ RT60 ประมาณ **15.9 วิ (Canon) / 4.7 วิ (ATY)** · **Canon = เป็นไปไม่ได้ทางฟิสิกส์** (ไม่มีห้องไหน 16 วิ) → แปลว่า**หาช่วง "ปล่อยให้เสียงตาย" จริง ๆ ไม่เจอ** เพราะเล่นต่อเนื่องตลอด → **ตัวเลขนี้ใช้ไม่ได้ทั้งคู่ ทิ้ง**
4. **P3 ความดังตกตอนเปลี่ยนโน้ต (2.3/2.7 dB)** — ⚠️ **เชื่อได้น้อย:** ตัวจับ onset นับได้ **1,898 ครั้งใน Canon** ซึ่งมากเกินกว่าที่เชลโลจะสีจริงในเพลงยาว 5 นาที → แปลว่ามันจับ artifact/เสียงรั่วปนมาด้วย · ใช้ได้แค่เป็น**ทิศทางหยาบ ๆ** ("ตกน้อย ไม่ใช่ตีหัวใหม่แรง ๆ") ไม่ใช่ค่าที่เอาไปตั้งพารามิเตอร์
5. **Canon = เชลโลร้องนำจริงไหม** — ผลวัดว่าใช่ (median B3) แต่ **P'Aim ฟังยืนยันจะปิดเคสได้เลย** (เพราะมันค้าน brief)

## ข้อเสนอ 1 บรรทัดถึง PM

**ถ้าจะหยิบทำอย่างเดียว: ทำข้อ 1 (arc 13–15 dB ต่อท่อน + ไคลแมกซ์ ~58%)** — ตรงกันทั้ง 2 เพลง · แก้ได้ด้วย `dynamics.js` ที่มีอยู่ · ห่างของจริงมากสุด (10 เท่า) · **และไม่ต้องพึ่งเชลโลเลย** (ใช้กับเปียโนทองที่ P'Aim ชอบอยู่แล้วได้ทันที)

**ส่วนเชลโล:** ผลวัดชี้ว่าปัญหาน่าจะไม่ใช่แค่ sample — **เราให้มันทำผิดหน้าที่** (เดินเบส) ทั้งที่ของอ้างอิงทั้ง 2 เพลงให้มัน **ร้องนำในย่าน B3** · เรื่องนี้ควรบอกสาย `cello-bakeoff` ก่อนที่จะไปตัดสินว่า sample ฟรีไม่ไหว

- ⚖️ ไม่มีไฟล์เสียง/stem/โน้ตของทั้ง 2 เพลงอยู่ใน repo
