## ทำอะไรไป

เพลง **#1 พระเจ้าเป็นความรัก** คีย์ E · 102 bpm · ตัดท่อนแรก **20.3 วินาที** (ตัดที่หัวบรรทัด ไม่ตัดกลางคำ)

ทุกคลิปใช้ **วาทยกรเปียโนทองตัวเดิมเป๊ะ** ตามที่ P'Aim สั่ง — `arrange()` + preset `piano-arrangement`
("เปียโนบรรเลง") + `splendid-grand` = เส้นทางเดียวกับที่ deploy จริงรอบ 27 **ไม่ได้แตะโค้ดที่ deploy แล้วเลย**
(`git diff studio-shell-redesign -- src/lib src/views src/components` = ว่าง · โค้ด spike อยู่ใน `src/spikes/` แยกต่างหาก)

หน้าที่เชลโล = **ร้องนำทำนอง** (role `melody`) · เปียโนคลอ (`inner` 63 + `bass` 9 + `emb` 2 = 104 events ต่อคลิป)

### ความยุติธรรม — พิสูจน์ด้วยการวัด ไม่ใช่พูดลอย ๆ

1. **เปียโนเหมือนกันจริง** — เรนเดอร์เฉพาะฝั่งเปียโนของ A/B/C แล้วเทียบทีละ sample:
   ต่างกันสูงสุด **3×10⁻⁸** (= ปัดเศษ float32 · ราว −150 dB · หูมนุษย์ไม่มีทางได้ยิน) → **เหมือนกันเชิงตัวเลข**
   ทำได้เพราะ `arrange()` เป็น pure function + ป้อน `songId` เป็นเมล็ด RNG เดียวกัน (ตรวจแล้ว: perf เท่ากันเป๊ะ)
2. **เชลโล 3 ตัวดังเท่ากัน** — วัดจากการเล่นท่อนนี้จริง ๆ แล้วปรับ: A `+1.8 dB` · B `−6.0 dB` · C `0.0 dB`
   → RMS ออกมา **−24.0 dB เท่ากันทั้ง 3 ตัว**
3. **ทุกคลิปดังเท่ากันตอนเล่น** — normalize เป็น RMS −24.0 dB (peak −8.1 ถึง −9.7 dB · ไม่มีคลิป)
4. **แก้จูนให้ตรงเสียงทั้ง 3 ตัว** — ดูหัวข้อ "จูนเพี้ยน" ข้างล่าง

> ⚠️ **จุดที่เกือบพลาด:** ตอนแรกจับความดังจาก "ค่าเฉลี่ยทั้งไลบรารี" ซึ่ง**ไม่พอ** — Karoryfer ช่วงเสียงสูง
> เบากว่าช่วงเสียงต่ำถึง **14.7 dB** ส่วน SSO ต่างกันน้อยกว่า พอทำนองอยู่ช่วง MIDI 59–73 เลยกลายเป็น
> **B ดังกว่า A อยู่ 6.5 dB** → หูจะตัดสินว่า B "เพราะกว่า" ทั้งที่จริงแค่ **ดังกว่า**. แก้แล้วโดยวัดความดัง
> **จากท่อนที่ใช้จริง** ไม่ใช่ค่าเฉลี่ยทั้งไลบรารี

### ✅ negative delay — รับเข้ามาแล้ว (PM ส่งเข้าระหว่างสายกำลังรัน · `23550ef`)

**ทำแล้วครับ** ตามสเปก `docs/pm/audio-round2-techniques.md` — และ**วัดเอง ไม่ได้ยกเลข "30–80ms" ของที่ปรึกษามาใช้**
(สเปกห้ามไว้ชัดเจน · เลขนั้นคือเชลโลจริง ไม่ใช่ sample เรา)

วัด "เวลาที่เสียงไต่ถึงครึ่งหนึ่งของระดับยืน" ของ**ทุกไฟล์** แล้วเอา median ต่อไลบรารี:

| | เสียงเริ่มมา | หัวเสียงไต่ (t50) | **ไต่จริง** (หักช่วงเงียบหน้าไฟล์) | เลื่อนให้เริ่มก่อน |
|---|---|---|---|---|
| **เปียโน Grand** (ตัวอ้างอิง) | 0 ms | **0 ms** (เคาะปุ๊บดังปั๊บ) | 0 ms | — |
| A Karoryfer | 0 ms | 20 ms | 20 ms | −20 ms |
| B SSO | 0 ms | 58 ms | 55 ms | −58 ms |
| **C Iowa** | 5 ms | **245 ms** ⚠️ | **240 ms** | −245 ms |

**✅ เช็กแล้วว่าไม่ใช่ "ไฟล์มีช่วงเงียบนำหน้า":** ถ้า Iowa ช้าเพราะมีอากาศว่างหัวไฟล์ วิธีแก้คือ**ตัดหัวไฟล์**
ไม่ใช่เลื่อน onset และคำอธิบาย "หวูดเรือ" ก็จะผิด → **วัดแยกแล้ว: Iowa เสียงเริ่มมาตั้งแต่ 5 ms แต่กว่าจะดังถึงครึ่ง
ใช้ 245 ms = ไต่จริง 240 ms** → **เป็นการบวมของคันชักจริง ไม่ใช่ช่วงเงียบ** → ทั้งการชดเชยและคำอธิบายถูกต้อง

> 📏 ความละเอียดการวัดมีผลจริง: ตอนใช้เฟรม 10 ms ได้ Karoryfer = 40 ms ซึ่งเป็น**ความคลาดเคลื่อนของเฟรมเอง** —
> ลดเป็นเฟรม 5 ms ได้ **20 ms** (ค่าที่ใช้จริงตอนนี้) · Iowa/SSO แทบไม่ขยับ (250→245 · 55→58)

**นี่คือหลักฐานที่ตรงกับสมมติฐานของ PM เป๊ะ:** เปียโนดังทันที เชลโลไต่ช้า → ถ้าไม่แก้ เชลโล**ตามหลังทุกคลิป**
→ P'Aim อาจเทหมด 3 ตัวเพราะ**เราตั้งเวลาผิด** ไม่ใช่เพราะ sample ห่วย (false negative ตามที่ PM กลัวจริง ๆ)

**และมันอธิบาย "หวูดเรือ" ได้ด้วย:** Iowa ไต่ **245 ms** = ช้ากว่า Karoryfer **12 เท่า** — เสียงที่ค่อย ๆ บวมขึ้น
ช้าขนาดนี้ = อาการ "หวูดเรือ" ตรงตัว **นี่คือตัวเลข ไม่ใช่ความเห็นผม**

**PM ให้ค้านถ้ามีหลักฐานว่า PM คิดผิด — ผมหาแล้ว ไม่เจอ ยืนยันว่า PM ถูก:** ที่ PM เผื่อไว้ว่า "legato map อาจตัด
หัวเสียงมาให้แล้ว = ไม่ต้องชดเชย" — **ใช้ไม่ได้กับรอบนี้** เพราะผมใช้ชุด `Samples/sus` ตรง ๆ (ไม่ได้ใช้
`*legato*.sfz` ตาม brief ข้อ 2 ที่ให้เอาดิบ ๆ ก่อน) → หัวเสียงยังเต็ม ๆ อยู่ = **ต้องชดเชยจริง**

ปลอดภัยกับการทดลอง: วัดได้ · deterministic (ไม่สุ่ม → MP3 == live) · แก้ข้อบกพร่องเชิงเวลา ไม่ใช่แต่งหน้าให้ตัวไหนชนะ
· **ตรวจแล้วว่าเลื่อนแค่เชลโล — ฝั่งเปียโนยังเหมือนกันเป๊ะทั้ง 3 คลิป (3×10⁻⁸ เท่าเดิม)**
· ค่าเลื่อนอ่านจาก `preset.json → plengMeta.attackMs` ที่เครื่องมือวัดแล้วเขียนให้ (ไม่ได้พิมพ์เลขลงโค้ด)
· **มี checkbox ปิดได้** ถ้าอยากฟังว่าต่างจริงไหม

📌 **จุดที่ผมตัดสินใจเอง (ขอ PM ค้านได้):** สเปกเขียนว่า "time-to-peak" แต่ค่า time-to-peak จริงคือ 320–730 ms
ซึ่ง**เลื่อนตามนั้นไม่ได้** (โน้ตจะมาก่อนจังหวะจนเพี้ยน) → ผมใช้ **"เวลาไต่ถึงครึ่งระดับ" (t50)** แทน ซึ่งเป็นจุดที่
หูใช้ระบุตำแหน่งโน้ต · ที่พักไว้ (pan / layer crossfade / sustain-tail) **ไม่ได้ทำ** ตามที่สเปกสั่ง

## ข้อจำกัด / สิ่งที่ยังไม่เท่ากันเป๊ะ (พูดตรง ๆ)

1. **B วนลูปได้ · A/C ไม่ได้** — ผมเปิด loop ให้ B เพราะ **loop point ติดมากับไลบรารีเอง** (ไม่ใช่ผมประดิษฐ์)
   และไฟล์ B สั้นมาก (1.5–3.0 s) ถ้าไม่ลูป โน้ตยาวจะขาดกลางคัน = แพ้เพราะเหตุผลที่ไม่ใช่เนื้อเสียง
   **แต่ก็แปลว่า B ไม่ได้ต่างจาก A/C แค่ "ไฟล์เสียง" — มันต่างที่ความสามารถด้วย** (ตรงนี้เลี่ยงไม่ได้จริง ๆ)
2. **ยังไม่ได้ทำ legato / vibrato / swell เทียม** ตาม brief ข้อ 2 (เอาดิบ ๆ ก่อน) — Karoryfer มี `*legato*.sfz`
   มาให้ ถ้า P'Aim ชอบ A ค่อยต่อยอด
3. **A/C เป็น mono · B เป็นสเตอริโอ** = ธรรมชาติของไลบรารี ไม่ได้แปลงให้เท่ากัน
   (ถ้าบังคับ B เป็น mono ก็เท่ากับทำลายจุดเด่นของมัน)
4. **ใช้ระดับความดังชั้นเดียว** (Karoryfer `mf` คันชักลง `_d`) ตาม brief ข้อ 1 — ไม่ยัด p/mp/mf/f เป็น velRange
