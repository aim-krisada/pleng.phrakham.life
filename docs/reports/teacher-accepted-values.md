## 3 · 2 คำถามที่เปลี่ยนกฎทั้งคลัง 400+ เพลง — ต้อง ping PM ทันทีที่ได้คำตอบ

**ก · ไคลแมกซ์ยึดอะไร**
- ทางที่ระบบใช้อยู่: โน้ตทำนองสูงสุด ถึงจะไปอยู่ท่อนร้องก็ตาม
- ทางอีกทาง: ต้องอยู่ในท่อนฮุกเสมอ แล้วหาโน้ตสูงสุด*ภายใน*ท่อนนั้น
- **ถ้าตอบผิดทางต้องอัดใหม่ทั้งคลัง** · จุดที่ต้องแก้ = `climaxPlan()` ใน `src/lib/arranger/teacher.js`

**ข · ท่อนรับถี่กว่าท่อนร้องเท่าไร**
- 1.4 เท่า (ค่าที่ใช้อยู่) หรือ 2.8 เท่า (อัดเตรียมไว้แล้ว) หรือค่าอื่นที่ครูให้
- จุดที่ต้องแก้ = `BAND_STYLE` + ตัวเลือก `refrainDensity` ใน `src/lib/arranger/teacher.js`
