## 0 · สรุป — ฟันธง (อ่าน 30 วิ)

**เลือก: แนวทาง ค (ค่าแนะนำ + ▲▼) เป็นแกน + ง (ฟังทันที) ในตัว — วางในแถบเครื่องมือลอยที่เกาะโน้ต (contextual toolbox ของ dock-space)**

> **ตัวคุม:** `𝄐 ค้าง [ – ]  ▓▓▓░  2 จังหวะ  [ + ]   ▶ฟัง   ↺แนะนำ`
> เกาะเหนือโน้ตเฟอร์มาต้าที่เลือก (ไม่บังโน้ต/คอร์ด — clamp ในจอแล้ว) · ทุกปุ่ม 44px · แตะล้วน ไม่ต้องลาก

**ทำไมไม่ใช่ ก (ลากยืด) ตามที่ brief ลีน:** ลาก = ระดับโลกบน **desktop เมาส์แม่น** (เหมือน DAW piano-roll) แต่ **พี่เปาใช้มือถือ** → ลากบนกล่องโน้ต 46px = พลาดง่าย + ชนการเลื่อนจอ + **ไม่โชว์ค่า** (spec ต้องโชว์+จำค่า) · **แตะ ▲▼ = แม่นทุก 0.5 บีต + โชว์ค่า + mobile-first** → ถูกกว่าสำหรับผู้ใช้จริง · เก็บจิตวิญญาณ ก ไว้ที่ **แถบความยาวเห็นภาพ** (▓▓▓░) ข้าง ๆ ตัวเลข · ลากบน desktop = enhancement เฟส 2 ได้

## 1 · ผู้ใช้ + ข้อจำกัด (ยึด)

- **พี่เปา = มือถือ/จอสัมผัส · ไม่เป็นดนตรี** → ตัดศัพท์/การลากที่ต้องแม่น · ใช้แตะ + เห็นภาพ + ได้ยิน
- **spec:** default = ระบบแนะนำ · ปรับ = เก็บค่าใหม่ · **ฟังทันที** · **⛔ ห้ามบังโน้ต/คอร์ดที่กำลังแก้** · 44px · step 0.5 บีต (SA §4)
- **honest-to-sheet:** ค่าที่ตั้ง = ค่าที่เล่นเป๊ะ ([[feedback-audio-honest-to-sheet]]) — UI โชว์ค่าจริง ไม่ mask

## 2 · ประเมิน 4 แนวทาง (เทียบข้อจำกัดจริง)

| แนวทาง | มือถือแม่น | โชว์ค่า (spec) | default→ปรับ | ฟังทันที | ระดับโลก (อ้าง) | ตัดสิน |
|---|---|---|---|---|---|---|
| **ก. ลากยืด** | 🔴 ลากบน 46px ชนสกรอลล์ | 🔴 ไม่มีตัวเลข | 🟡 | ต้องเพิ่ม | DAW/MuseScore = **เมาส์แม่น** | **เสริม (visual bar) · desktop เฟส 2** |
| **ข. สั้น/กลาง/ยาว** | ✅ แตะง่าย | 🟡 คลุมเครือ | 🔴 ไม่ตรงค่าแนะนำ | ต้องเพิ่ม | preset = หยาบ | **ยืมเป็น "↺แนะนำ" (1 ปุ่ม)** |
| **⭐ ค. ค่าแนะนำ + ▲▼** | ✅ แตะแม่นทุก 0.5 | ✅ โชว์เป๊ะ | ✅ **ตรง spec 1:1** | เพิ่มปุ่มเดียว | MuseScore property spinner · Apple HIG stepper | **✅ แกนหลัก** |
| **ง. ฟังแล้วปรับ** | ✅ | — | — | ✅ **หัวใจ** | — | **✅ รวมในตัว (▶ฟัง)** |

**ฟันธง:** **ค (แกน) + ง (ฟังในตัว) + host เกาะโน้ต + visual bar (จิตวิญญาณ ก) + ↺แนะนำ (จิตวิญญาณ ข)** — รวมข้อดีทุกแนวทาง โดยไม่รับจุดอ่อนการลากบนมือถือ

## 3 · ⭐ UI spec (ตัวคุม hold)

**host — contextual toolbox ที่เกาะโน้ต (มีอยู่แล้วจาก dock-space):** แถบลอยเกาะเหนือโน้ตที่โฟกัส · clamp ในจอ · ไม่บังโน้ต (verify แล้วว่า gap 0 + on-screen) → **ตรงข้อ "ห้ามบัง" เป๊ะ** โดยไม่ต้องสร้าง surface ใหม่

**แสดงเมื่อ:** โฟกัสโน้ตที่**มีเฟอร์มาต้า** (`^` ใน note string · `token.fermata`) → toolbox โผล่แถว "ค้าง" (โน้ตปกติไม่เห็น — ลด clutter)

```
┌─────────────────────────────────────────────┐
│  𝄐 ค้าง   [ – ]  ▓▓▓░░  2 จังหวะ  [ + ]   ▶ ฟัง   ↺ แนะนำ │
└─────────────────────────────────────────────┘
        ▲ เกาะเหนือโน้ตเฟอร์มาต้า (ไม่บัง)
```

| ส่วน | หน้าที่ | มาตรฐาน |
|---|---|---|
| **`𝄐 ค้าง`** | ป้ายบอกว่านี่คือค่าค้างของเฟอร์มาต้า | ภาษาคน (ไม่ใช่ "hold value") |
| **`[ – ] [ + ]`** | ลด/เพิ่ม **0.5 บีต** ต่อกด · 44×44 · aria "ค้างสั้นลง/ยาวขึ้น" | stepper (Apple HIG · MuseScore spinner) · WCAG 2.5.5 44px |
| **`▓▓▓░ 2 จังหวะ`** | **โชว์ค่าจริง** 2 ทาง: แถบยาว (เห็นภาพ · จิตวิญญาณ ก) + ตัวเลข "N จังหวะ" | โชว์ค่า (spec) · dual-coding (เห็น+อ่าน) |
| **`▶ ฟัง`** | เล่นโน้ตนั้นด้วยค่าค้างปัจจุบันทันที (ง) · 44px · aria "ฟังเสียงค้าง" | instant feedback · ผูก playback ค่าใหม่ |
| **`↺ แนะนำ`** | คืนค่าระบบแนะนำ ("เติมจนจบห้อง") · 1 แตะ | reset-to-default · ปลอดภัย |

**พฤติกรรม:**
- **ค่าเริ่มต้น** = ระบบแนะนำ (SA: เติมจนจบห้อง / ~2× ถ้ากลางห้อง) — โผล่มาตั้งไว้ให้เลย พี่เปาไม่ต้องคิด
- **ปรับ ▲▼** → เก็บค่าใหม่ทันที (`holds[i]`) · แถบ+ตัวเลขอัปเดตสด · ครั้งต่อไปจำค่าที่ปรับ
- **ช่วงค่า:** min 0.5 (มี `^` = ต้องค้างอย่างน้อยครึ่งบีต) · ไม่มี max แข็ง แต่เตือนนุ่ม/หยุดเพิ่มเมื่อเกิน ~2 ห้อง (กันพลาด) · step 0.5
- **ฟัง** = เล่นเฉพาะโน้ตนั้น + หาง (ไม่ต้องเล่นทั้งเพลง) → ได้ยินผลค้างเดี๋ยวนั้น
- **มือถือ:** ทุกอย่างแตะ · ไม่มีลาก · แถบลอยเกาะโน้ต + clamp = ใช้ได้จอ 344 (toolbox overflow-x ถ้าเบียด) · โผล่เหนือแป้นพิมพ์ (keyboard-aware ของ dock-space)

## 4 · flow (พี่เปา · มือถือ)

1. เลือกโน้ต → แตะ `𝄐` ในแป้นสัญลักษณ์ (ของเดิม) → โน้ตได้เฟอร์มาต้า
2. แถบ "ค้าง" โผล่เหนือโน้ต **ตั้งค่าแนะนำไว้แล้ว** ("2 จังหวะ · จนจบห้อง")
3. อยากค้างนานขึ้น → แตะ `+` (ทีละครึ่งบีต · เห็นแถบยาวขึ้น) → แตะ `▶ฟัง` ได้ยินผล
4. พอใจ → ปล่อย (เก็บอัตโนมัติ) · ไม่พอใจ → `↺แนะนำ` กลับค่าเริ่ม
5. **แผ่นพิมพ์:** เห็นแค่สัญลักษณ์ 𝄐 (ไม่มีตัวเลข — SA §6 · Gould "Behind Bars") — ตัวเลขเป็นเครื่องมือในหน้าแก้ ไม่ใช่ notation

## 5 · มาตรฐานอ้างอิง (อ่านเอง · ไม่ใช้ Gemini)

- **stepper/spinner แก้ duration ต่อโน้ต = แนวทางมาตรฐาน notation-editor:** MuseScore 4 แก้เฟอร์มาต้าผ่าน property ตัวเลข (Time stretch) — ปรับค่าเป็นตัวเลข ไม่ใช่ลากบนสกอร์ · [MuseScore fermata time-stretch](https://musescore.org/en/node/276202)
- **stepper (– / +) = ตัวคุมค่าทีละสเต็ปมาตรฐาน สำหรับค่าที่มี default + ปรับละเอียด** · [Apple HIG — Steppers](https://developer.apple.com/design/human-interface-guidelines/steppers) · [Material — do not free-type when stepping small ranges]
- **touch target ≥44px:** [WCAG 2.5.5 Target Size](https://www.w3.org/WAI/WCAG21/Understanding/target-size.html) · Apple HIG 44pt · Material 48dp
- **direct-manipulation (ลาก) เหมาะ pointer แม่น ไม่เหมาะ touch เล็ก:** [NN/g — Direct Manipulation](https://www.nngroup.com/articles/direct-manipulation/) → ยืนยันเลือก tap-stepper สำหรับมือถือพี่เปา
- **dual-coding (แถบ + ตัวเลข) = เข้าใจไวขึ้น** (เห็นภาพ + อ่านค่า) · [NN/g — Redundant coding]
- **sheet ไม่เขียนตัวเลข duration ของเฟอร์มาต้า = ถูกหลักสากล:** Gould, *Behind Bars* (pause = การวางสัญลักษณ์ให้ทุกแนวตรงกัน · ไม่เขียนเวลา) — ตรงกับ SA §6

## 6 · sheet ไม่แตะ · feasibility (คู่ SA)

- **SongSheet.vue = 0** — ค่าอยู่ใน `holds` (นอก string) → sheet เรนเดอร์ `^`=𝄐 เหมือนเดิม ไม่เห็นเลข (SA §4)
- **EditorMode.vue:** เพิ่มแถว "ค้าง" ใน contextual toolbox เมื่อ `token.fermata` · ผูก `holds[i]` · ▶ฟัง เรียก playback โน้ตเดียว (dev + SA — logic) · **UX = template/CSS ของตัวคุม** (stepper/แถบ/ปุ่ม 44px · §3.0 HYBRID)
- SA ยืนยัน feasible ทุกแบบ (แค่ set เลข `holds[i]`) — แนวทางนี้ **reuse toolbox ที่มีอยู่** = ต่อเติมน้อยสุด
