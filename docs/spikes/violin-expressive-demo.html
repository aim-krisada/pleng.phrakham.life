🎻 ไวโอลินเดี่ยว — "ใส่ชีวิต" vs "นิ่ง"

เสียงเดียวกัน (Iowa Public Domain หลายระดับ) · ต่างแค่ "ชั้นการแสดงออก" ที่ผมเติมให้ตรงกับไวโอลินจริงที่พี่เอมชอบ (วัดมาจาก Amazing Grace Park Ji-hye / Ishikawa): vibrato ลึก 5–7 Hz · คันชักดัง-เบาในตัวโน้ต (swell) · ไถลเชื่อมโน้ต (portamento) · เสียงเปิดสว่างตอนดัง · หายใจปลายวรรค. "นิ่ง" = ปิดชั้นนี้ = เสียงออร์แกนแบบเดิม

เทียบ A/B (กดสลับแล้วเล่นใหม่)

✨ ใส่ชีวิต (expressive)vibrato + swell + ไถลโน้ต + เปิดสว่าง = โหยหวน มีอารมณ์
➖ นิ่ง (organ-like)โน้ตตรง ไม่สั่น ไม่สเวลล์ = แบบที่ฟังแล้วเหมือนออร์แกน
แตะ "เล่น" ครั้งแรกจะโหลดเสียง (~1 วิ)

ตัวเลขอ้างอิงที่วัดจากไวโอลินจริง: vibrato ~44–54 cent @ 5–7 Hz · ของเดิม (Iowa ดิบ) = ~2–3 cent (แทบไม่สั่น = ต้นเหตุ "ออร์แกน"). ชั้นนี้ทำ vibrato ทั้ง พิตช์+ความดัง พร้อมกัน (คันชักจริงสั่นทั้งคู่) + ค่อยเข้าหลังเริ่มโน้ต (ไม่สั่นทันที) + ลึกขึ้นในโน้ตยาว.
