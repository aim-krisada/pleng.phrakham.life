## บทเรียนของรอบนี้ ที่คนรอบหน้าจะพลาดซ้ำ

1. **ใบงานของเพลงอยู่ที่อัมกิต `v3/pleng` ไม่ใช่ GitHub issue** เลขใบที่คอมมิตอ้างถึงคือเลขของอัมกิต
   รอบนี้เกือบเปิดเป็น GitHub issue ซึ่งจะได้เลขคนละชุดกับที่คอมมิตอ้างถึง
2. **เซสชันคลาวด์เปิดคำขอรวมและใบในนาม `aim-agent` ไม่ได้** proxy ของเซสชันเขียนทับ `Authorization`
   ของทุกคำขอที่ไป `api.github.com` ด้วยกุญแจบัญชีที่พี่เอมเชื่อมไว้ ยิงด้วยกุญแจมั่วหรือไม่ใส่เลย
   ก็ยังได้ `aim-krisada` (ทดสอบ 19 ต.ค. 2569) **ต้องยิงจากเครื่องพี่เอม หรือที่อื่นที่ไม่ผ่าน proxy ตัวนี้**
3. **เขียนลงอัมกิตต้องเป็นภาษาไทยระดับ ม.ต้น ห้ามมีชื่อไฟล์ ชื่อฟังก์ชัน ชื่อตัวแปรในเนื้อใบ**
   คนอ่านมีพี่เปาซึ่งไม่อ่านโค้ด รายละเอียดโค้ดให้อยู่ในคำขอรวมเท่านั้น
4. ข้อ 2 เป็นเรื่องที่คนอื่นจะพลาดซ้ำแน่ ตอนนี้จดไว้ใน `CLAUDE.md` ของ pleng ก่อน
   ถ้าเจอรอบสองในโปรเจกต์อื่น ให้ย้ายขึ้น `C:\gl\CLAUDE.md`
