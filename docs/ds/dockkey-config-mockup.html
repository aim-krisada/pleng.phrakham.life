สลับ 📱/🖥️ แล้วกดปุ่ม ⚙ ในแถบ — จะเห็นว่ามือถือกับเดสก์ท็อป “ตั้งค่า” คนละท่า (ตามที่พี่เอมเคาะ)

ของเดิมมีแล้ว (ปัก · ▲▼ · ตั้งค่าในตัว · ย่อแถบ)ใหม่จริง (ลากขอบ · หน้าเต็มจอมือถือ · แสดงชื่อ · คืนค่า)

📱 มือถือ: กด ⚙ → เปิดหน้าเต็มจอ · กด “เสร็จ” กลับมาที่เดิม (เคอร์เซอร์ยังอยู่จุดเดิม)

ตั้งค่าแถบเครื่องมือ

ทำไมมือถือ ≠ เดสก์ท็อป (SOP)

เดสก์ท็อป (เมาส์): ตั้งค่าเปิดข้างแถบ + ลากขอบย่อได้ (จุดเขียวมุมขวาบน)

มือถือ (นิ้ว): ⚙ เปิดหน้าเต็มจอ เลือกเสร็จกด “เสร็จ” กลับจุดเดิม — เพราะ popup ลอยบนจอเล็กคับ + นิ้วลากขอบเล็งยาก

อ้าง: Material full-screen dialog · Apple Dynamic Type · NN/g (touch ไม่มี hover)

“ใหญ่ไป” = กินพื้นที่จอ → ลด footprint

  • ปุ่มเดิม 44px อยู่แล้ว (ย่อต่ำกว่านี้ไม่ได้ · มาตรฐานนิ้ว)
  • ลดที่ = โชว์ปุ่มน้อยลง (เก็บในตั้งค่า) + preset กะทัดรัด + ลากขอบ/ย่อแถบ
  • ⭐ แสดงชื่อปุ่ม + ชื่ออ้างอิง = แก้ pain สื่อสารพี่เปา (แตะปุ่มดู id)
