เลื่อน “ขนาดแถบ” เห็นแถบย่อสด · เปิด “แสดงชื่อปุ่ม” เห็นชื่อไทยทุกปุ่ม · ปัก/ถอนปุ่มว่าจะโชว์ตัวไหน · แตะปุ่มบนแถบเพื่อดู “ชื่ออ้างอิง + id”

แตะปุ่มบนแถบ เพื่อดูชื่ออ้างอิงที่ทั้งทีมใช้เรียก + id สำหรับ dev/test

⚙ ตั้งค่าแถบ

ขนาดแถบ

แสดงชื่อปุ่มชื่อไทย = ป้าย = ที่ทีมใช้เรียก

ปุ่มที่แสดงบนแถบ

    ⭐ 1 ชื่อ = 4 หน้าที่ (ระบบชื่ออ้างอิง)

    ทุกปุ่มมี ชื่อไทยเดียว ที่เป็นทั้ง —

    • ป้ายบนปุ่ม
    • ชื่อที่ทีมเรียก
    • accessible-name (a11y)
    • tooltip

    + id (ascii คงที่) แยกไว้สำหรับ code/test → พี่เปาพูด “ปุ่มฟังท่อน” ทุกคนรู้ว่า play ไม่ต้อง capture จอ

    ทำไม “ขนาด = ตั้งค่า” ไม่ใช่ลากขอบ

    บนมือถือ ลากมุมย่อ = เล็งยาก. Apple Dynamic Type + Material density ทำ “ขนาด = ตัวเลือกในตั้งค่า” ให้ UI ปรับตาม — เราจึงใช้ 3 ระดับ. default กะทัดรัด 44px (เดิม 50px ใหญ่ไป) ยังผ่าน Apple HIG 44pt.
