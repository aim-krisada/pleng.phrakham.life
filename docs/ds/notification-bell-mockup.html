การแจ้งเตือน

    3 เพลงรอตรวจทั้งหมดตัวติดตามการตรวจ →

    ทำไม “รายการ” ไม่ใช่ “ตัวนับ”

    แต่ละแจ้งเตือน = item ที่มี {type, ข้อความ, ลิงก์, อ่านยัง} → กดแล้วไปที่เรื่องนั้นได้

    เพิ่มบทบาท/ประกาศทีหลัง = เพิ่ม type ใหม่ ไม่ต้องรื้อหน้าจอ (approver→ผู้ส่ง→broadcast)

    pattern: GitHub/Gmail notification center · Material notifications

    เลข badge = “ยังไม่อ่าน” (ไม่ใช่ 94)

    badge = แจ้งเตือนที่ยังไม่อ่าน · อ่านแล้วลด (Apple: badge = unread เท่านั้น ไม่ใช่ตัวเลขคลัง)

    “ค้างกี่เพลง” = สรุปในหัวรายการ + ลิงก์ตัวติดตามการตรวจ · 94 verified=false ไม่เด้ง

    a11y: ชื่อระฆังมี unread + role=status (WCAG 4.1.3)
