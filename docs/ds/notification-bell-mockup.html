ระฆังเตือน — “มีเพลงส่งเข้ามารอตรวจ” เห็นเองไม่ต้องถาม

กดปุ่ม “จำลองส่งเพลงใหม่” → ระฆังสั่น + เลขเพิ่ม + จุดเขียว(ใหม่) · กด 🔔 เปิดคิว → ตรวจ → เลขลด · เปิดคิวแล้วจุด “ใหม่” หาย (เลขยังอยู่จนตรวจจริง)

เพลง.พระคำ

คุณคือ พี่เปา (ผู้ตรวจ) · ระฆังจะโชว์เฉพาะผู้ตรวจ · เลข = เพลงที่ทีมส่งมารอตรวจทั้งคลัง

การแจ้งเตือน · 2 เพลงรอตรวจ

คิวรอตรวจ

    เลข vs จุดเขียว (ทำไมทั้งสอง)

    เลข = งานจริงที่ยังต้องตรวจ → ลดเมื่อตรวจจริงเท่านั้น (เหลือบเฉย ๆ ไม่หาย)

    จุดเขียว “ใหม่” = มีของเพิ่งเข้ามาตั้งแต่ครั้งก่อน → หายเมื่อเปิดคิวดู (Apple: เคลียร์เมื่อเห็นแล้ว)

    M3 Badges (dot=มีใหม่ · number=count) · Apple HIG Notifications

    คนพิการก็รู้ (a11y)

    ระฆังมีชื่อพร้อมเลข: “การแจ้งเตือน · 3 เพลงรอตรวจ” — โฟกัสได้ยินเลย

    เลขเปลี่ยน → โปรแกรมอ่านหน้าจออ่านให้เองโดยไม่แย่งโฟกัส (role=status + aria-atomic)

    WCAG 4.1.3 Status Messages (AA) · W3C ARIA22
