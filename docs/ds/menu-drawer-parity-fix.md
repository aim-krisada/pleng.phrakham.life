## 0. F60+ สรุปหัวตาราง (อ่านบรรทัดเดียวจบ)

พระคำ **ไม่มี drawer ด้านข้างเลย** — กด ☰ แล้วเมนู**กางลงเต็มหน้ากว้าง เป็นแถวใต้แถบหัว ดันเนื้อหาลง** (Bootstrap collapse) ลิงก์ชิดซ้ายเริ่มจากขอบซ้าย. ส่วนเพลง = **แผงลอย (drawer) เลื่อนเข้าจากขวา สูงเต็มจอ มีฉากดำคลุมทั้งจอ**. สองอันนี้คนละแบบโครงสร้าง + เพลงขัดข้อตกลง "เริ่มจากซ้าย". **ข้อเสนอหลัก:** เปลี่ยนเพลงให้กางลงเต็มกว้างแบบพระคำ (option A) — ตรงกับที่ P'Aim อธิบายว่า "nav กางจากซ้าย".

## 1. พระคำมือถือ — verify ของจริง (ไม่เดา)

**หลักฐาน live:** เปิด https://phrakham.life ที่ 412×915 → กด ☰ (ref "Toggle navigation") → วัด `getComputedStyle` + `getBoundingClientRect` สด:

```
.navbar-collapse (หลังกด ☰):
  position: static      ← อยู่ใน normal flow (ไม่ลอย/ไม่ overlay)
  top: 57  bottom: 448  ← เริ่มใต้แถวหัว แล้วกางลง
  left: 31  right: 381  width: 350 / 412  ← เกือบเต็มกว้างหน้า
  navbar height 456     ← เมนูดัน container สูงขึ้น = ดันเนื้อหาลง ไม่ทับ
  nav links left: 31 (เมนูหลัก) / 0 (เมนูย่อย)  ← ชิดซ้าย เริ่มจากขอบซ้าย
```

**สรุปพฤติกรรมพระคำ:**
1. **ทิศ:** กาง **ลงล่าง** ใต้แถบหัว — ไม่เลื่อนจากข้าง
2. **กว้าง:** **เต็มความกว้างหน้า** — ไม่ใช่แผงแคบชิดขอบ
3. **การวางตัว:** `position: static` = อยู่ในสายเนื้อหา **ดันเนื้อหาลง** — ไม่ใช่ overlay ลอยทับ
4. **สูง:** เท่าเนื้อเมนู (~391px) — ไม่ใช่เต็มจอ
5. **ไม่มีฉากดำ (backdrop)** — เนื้อหาแค่เลื่อนลง
6. **ลิงก์ชิดซ้าย** เริ่มจากขอบซ้าย
7. **เครื่องมือ (Aa ตัวอักษร / ⚙ ตั้งค่า / 📥 ดาวน์โหลด)** = **ไม่อยู่ในเมนูนำทาง** — เป็นปุ่ม dropdown มุมขวาบนของแถบหัว โผล่เห็นตลอด (`assets/pk-navbar.js` mount ต่อจากช่องค้นหา)

**กลไกในโค้ด:** เมนูนำทาง = Quarto/Bootstrap `navbar-collapse` มาตรฐาน (config `_quarto.yml:52-69`) · ที่ < 992px แสดง ☰ toggler + collapse กางลงเป็นแถวของตัวเอง (`theme.scss:89-95` ส่ง collapse ไป `order:101` = แถวเต็มกว้างใต้ toggler) · toolbar Aa/⚙/📥 เป็น library แยก `assets/pk-navbar.js` (คุมแค่ 3 ปุ่มมุมขวา ไม่ใช่เมนูนำทาง)

## 2. เพลงมือถือ — verify ของจริง

**หลักฐาน live:** เปิด https://pleng.phrakham.life ที่ 412×915 → กด ☰ → วัดสด (จับตอนกางเข้า):

```
.sb-drawer (หลังกด ☰):
  position: fixed       ← ลอยทับ ไม่อยู่ในสายเนื้อหา
  right (CSS): 0px      ← ยึดขอบขวา
  width: 320  height: 915 (เต็มจอ 100dvh)
  animation: sb-drawer-in  (translateX 100% → 0 = เลื่อนเข้าจากขวา)
.sb-backdrop:
  position: fixed  inset: 0  (ฉากคลุมเต็มจอ 412×915)
  ลิงก์ในแผง = ชิดซ้าย (แต่ตัวแผงยึดขวา)
```

**สรุปพฤติกรรมเพลง:** แผงลอย (off-canvas drawer) กว้าง `min(84vw,320px)` **ยึดขอบขวา สูงเต็มจอ เลื่อนเข้าจากขวา + ฉากดำคลุมทั้งจอ** · เครื่องมือ (ตัวอักษรไทย) อยู่ **ในแผง** ใต้เส้นคั่น

**กลไกในโค้ด:** `src/components/ShellBar.vue:116` (`<aside class="sb-drawer">`) + `:145` (backdrop) · CSS `src/styles.css:355-372` (`position:fixed; right:0; ... translateX(100%)→0`) + `:429` (`.sb-backdrop inset:0`) · **live มาตั้งแต่ deploy รอบ 22 — ไม่ใช่ของใหม่**

## 4. ข้อเสนอปรับเพลงให้ตรงพระคำ

### 🟢 Option A — parity แท้: กางลงเต็มกว้างแบบพระคำ (แนะนำ)
เปลี่ยนแผงลอยขวา → **แผงกางลงเต็มความกว้าง ใต้แถบหัว ชิดซ้าย ดัน/คลุมเนื้อหาลงมา** (เหมือน Bootstrap collapse ของพระคำเป๊ะ) — **ตรงกับที่ P'Aim อธิบายว่า "nav กางจากซ้าย"** · เอาฉากดำออก (หรือเบาลง) · เนื้อในเดิม (ลิงก์ + หมวดเครื่องมือ) คงไว้ทั้งหมด
- **ข้อดี:** ตรงพระคำจริง 100% · แก้ครบทั้ง 6 จุดต่างโครงสร้างในทีเดียว · เลิก maintain off-canvas + backdrop
- **scope:** `src/components/ShellBar.vue` (`.sb-drawer` `<aside>` + เอา/ปรับ backdrop) · `src/styles.css:355-372` (เปลี่ยน `position:fixed;right:0;100dvh` → บล็อกกางลงเต็มกว้างใต้แถบ · เปลี่ยน animation เลื่อนขวา → กางลง) · `:429` backdrop · `:437` guard
- **ระดับงาน/เสี่ยง:** 🟡 กลาง (เขียน container CSS ใหม่ ~15-20 บรรทัด · markup เดิมส่วนใหญ่คงได้) · ต้อง retest sticky header + z-index + 360/412 + no h-scroll + target-size (Tier B real browser)

### 🟡 Option B — KISS ขั้นต่ำ: ยึดซ้ายแทนขวา (fallback)
คงแผงลอยเดิม แต่**สลับมายึดซ้าย + เลื่อนเข้าจากซ้าย**: `right:0`→`left:0` · `border-left`→`border-right` · เงา `-8px`→`+8px` · `translateX(100%)`→`translateX(-100%)`
- **ข้อดี:** แก้ ~5 บรรทัด CSS เสี่ยงต่ำสุด · สนอง "เริ่มจากซ้าย" ตามตัวอักษร
- **ข้อเสีย:** **ยังเป็นแผงลอยข้าง ≠ พระคำ** (ยังต่าง 5/6 จุดในตาราง) — แก้แค่ทิศ ไม่ได้ parity จริง
- **scope:** `src/styles.css:355-372` เท่านั้น

### 🔴 Option C — แค่จัดลิงก์ชิดซ้าย (ไม่พอ)
ลิงก์ในแผงชิดซ้ายอยู่แล้ว (§2) → ไม่แก้อะไรเลยก็ยัง "ชิดซ้าย" แต่**ไม่สนอง P'Aim** เพราะแผงยังมาจากขวา → **ตัดทิ้ง**

**👉 SA แนะนำ Option A** — เป็น parity แท้และตรงกับคำอธิบายของ P'Aim ("nav กางจากซ้าย") · ถ้า pk pm4/P'Aim อยากเปลี่ยนน้อยสุดก่อน ค่อยลง Option B เป็นก้าวชั่วคราว

**หมายเหตุ "ที่อยู่เครื่องมือ" (ช่องสุดท้ายตาราง):** พระคำวางเครื่องมือเป็น dropdown มุมขวาบน (โผล่ตลอด) · เพลงวางในแผง — **ไม่รวมในข้อเสนอนี้** เพราะสเปกร่วม (`menu-drawer-spec.md` หมายเหตุ pk pm4) ระบุ **layout/ลำดับเครื่องมือ = per-site ไม่ใช่ contract** · ยกไว้ให้ pk pm4 ตัดสินถ้าจะเอา parity ลึกกว่านี้
