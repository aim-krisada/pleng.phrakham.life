เครื่องมือติดกับ “สิ่งที่เลือก” — จิ้มอันไหน เครื่องมือของอันนั้นโผล่ตรงนั้น

ลองจิ้มโน้ต · ห้อง · บรรทัด · หรือหัวท่อน ในจอด้านล่าง — เครื่องมือของสิ่งนั้นจะโผล่มาติดตรงนั้น และสิ่งที่เลือกจะถูกไฮไลต์ให้เห็นชัด

ไม่ได้เลือกอะไร = จอสะอาด — เห็นแค่แถบระดับเอกสาร · จิ้มสิ่งใดสิ่งหนึ่งเพื่อดูเครื่องมือของมัน

✅ เอา “ขนาดกลาง” — toolbox เกาะติด element ครบ 5 ระดับ

แบบ Canva / iPhone callout · จิ้ม = เลือก · hover = แค่พรีวิวบนเดสก์ท็อป

  • ✗เล็ก (คงแถวเดิม + hover เฉย ๆ) — ไม่แก้ปัญหา 100 ปุ่ม และ hover ใช้บนมือถือไม่ได้
  • ✓กลาง (toolbox เกาะ element) — ตอบ “ลบบรรทัดไหน” ตรง · มือถือใช้ได้จริง · ต่อยอด slot-tools เดิม
  • ✗ใหญ่ (panel ลากได้แบบ Photoshop) — แถบลอยอิสระ บนจอมือถือ = บังโน้ต / ชนแป้นพิมพ์

3 อย่างที่ออกแบบ (ส่วนที่ยังขาด)

  • 1ตำแหน่ง consistent ทั้ง 5 ระดับ — จิ้ม→toolbox เกาะ “เหนือ” element + ลูกศรชี้ + ไม่หลุดจอ
  • 2ย้าย บรรทัด+ท่อน มาลอย — วันนี้อยู่ในแถบถาวร → ให้เกาะ element เหมือน โน้ต/ห้อง
  • 3hover-preview (เดสก์ท็อปเท่านั้น) — @media(hover:hover) · จิ้มคือความจริง hover คือน้ำตาล
