# ความหมายของเครื่องหมาย

**ช่อง "ใครตรวจ":** `เครื่อง✔` = ทำได้เลยวันนี้ · `เครื่อง+บราว์เซอร์` = ต้องมีตัวขับเบราว์เซอร์จริง · `เครื่อง+ตัวพิมพ์` = ต้องมีตัวพิมพ์ PDF · `เครื่อง+ไฟล์รายการ` = ต้องเขียนไฟล์รายการก่อน · `เครื่อง+ฟอนต์` = ต้องมีไฟล์ค่าระยะฟอนต์ · `คน` = คำถามปิด

**ช่อง "ที่มา":** ✅ = **ผมเปิดไฟล์ตรวจเองรอบนี้แล้ว** (มีเลขหน้า) · ⤳ = **สืบทอดจากร่างเดิม ⛔ ยังไม่ได้เปิดตรวจใหม่รอบนี้**
เลขหน้าทุกเลข = **เลขหน้าของไฟล์ PDF** ⛔ ไม่ใช่เลขหน้าที่พิมพ์ในเล่ม

3. **ปัญหาจริงไม่ใช่จำนวน แต่คือรายการไม่บอกว่าใครตรวจเมื่อไร** — ร่างเดิมทุกข้อ "ดูบังคับเท่ากันหมด" ⇒ ในทางปฏิบัติจึงไม่มีข้อไหนถูกไล่จริงเลย (สายการสร้างวันนี้ไม่มีประตูตรวจคุณภาพแม้แต่ประตูเดียว)
   ⇒ **การจัด 4 วงในไฟล์นี้ คือการแก้ที่ต้นเหตุ ⛔ ไม่ใช่การตัดให้สั้นลง**

**ถ้าจะพูดถึง "การตัด" ให้ตรงความจริง:** สิ่งที่ถูกตัดคือ **จำนวนข้อที่คนต้องอ่านทุกครั้ง** — จาก 136 (ในทางทฤษฎี) เหลือ **4 ข้อ** (วง 2 เท่านั้น) โดยเครื่องรับ 15 ข้อไปทำให้ในก้าวแรก

**⚠️ สิ่งที่เกณฑ์ `BLOOP` Table 2.3 บอกและเราต่างจาก N:**
N เสนอให้ชุด "ไล่ทุกครั้ง" = 4 ข้อของ 5.2.5 + **ทั้งหมวด จ 17 ข้อ** เพราะหมวด จ คืองานช่อง "บ่อย + คนมาก"
