## โจทย์

ปิดระบบสิทธิ์แล้ว ทีมช่วยกันตรวจเอง → ทุกคนต้อง **รู้เองว่ามีงานอะไรเกี่ยวกับตัวเอง** โดยไม่ต้องถาม:
- **ผู้ตรวจ (พี่เปา):** มีเพลงส่งมารอตรวจ
- **ผู้ส่งเพลง:** เพลงที่ส่ง อนุมัติแล้ว / ถูกส่งกลับให้แก้
- **อนาคต:** ประกาศรวมถึงทุกคน

## ทางแก้ (ฟันธง) — “ศูนย์แจ้งเตือน” แบบเดียวกับ GitHub / Gmail

ไม่ใช่แค่ตัวเลข แต่เป็น **รายการแจ้งเตือน** ที่กดเข้าไปทำงานต่อได้:
- ระฆัง 🔔 ที่หัวเว็บ + **เลข = แจ้งเตือนที่ยังไม่อ่าน**
- กดระฆัง → **รายการ**: “โม ส่ง ‘เพลง X’ มารอตรวจ”, “ ‘เพลง Y’ ของคุณอนุมัติแล้ว” … กดแต่ละอัน → **ไปที่เรื่องนั้นเลย + นับว่าอ่านแล้ว**
- ปุ่ม “อ่านทั้งหมด”

**ทำไมทำเป็นรายการตั้งแต่แรก:** เพิ่มบทบาท/ประกาศทีหลัง = **เพิ่มชนิดแจ้งเตือนใหม่ ไม่ต้องรื้อหน้าจอ** (นี่คือเหตุผลที่ผมฟันธงเป็น notification center ไม่ใช่ตัวนับ)

## จุดที่ฟันธงให้ (ไม่ให้พี่เอมต้องเลือก)

- **เลขบนระฆัง = “ยังไม่อ่าน”** (อ่านแล้วลด) — ตามมาตรฐาน Apple (badge = แจ้งเตือนที่ยังไม่อ่านเท่านั้น ไม่ใช่ตัวเลขคลัง)
- **“ค้างรอตรวจกี่เพลง”** = สรุปในหัวรายการ + ลิงก์ไป **หน้าตัวติดตามการตรวจ** — ไม่เอามาเป็นเลขระฆัง (94 เพลงเก่าที่ยังไม่ตรวจ = backlog ในหน้านั้น ไม่เด้งรบกวน)
- **มือถือ:** กดระฆัง → หน้าเต็มจอ · **เดสก์ท็อป:** รายการโผล่ใต้ระฆัง
- **คนพิการ:** ระฆังบอกจำนวนด้วยเสียง + อัปเดตอ่านให้เองไม่รบกวน (WCAG)

## ทำเป็นกี่เฟส

- **เฟส A:** ระฆัง + เลขยังไม่อ่าน + รายการ “งานเข้า” (ผู้ตรวจ) + อ่านแล้ว → **พี่เปาเห็นงานเข้า กดไปตรวจ**
- **เฟส B:** แจ้งผลถึงผู้ส่ง (อนุมัติแล้ว / ส่งกลับแก้)
- **เฟส C:** ลิงก์หน้าตัวติดตามการตรวจ (94 เก่า) + ชนิด “ประกาศ”

**SA ตรวจแล้ว = ทำได้** (ยกตัวนับขึ้นส่วนกลาง · เช็กเป็นระยะ · จำว่าอ่านอันไหนแล้ว)
