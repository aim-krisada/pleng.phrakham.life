## โจทย์

ตอนนี้ปิดระบบสิทธิ์แล้ว (คนนอกเห็นเฉพาะเพลงที่ตรวจแล้ว) → ทีมช่วยกันกดตรวจเอง พี่เอมไม่ต้องสั่งทีละเพลง · **แต่ผู้ตรวจ (พี่เปา) ต้องเห็นเองว่ามีเพลงส่งเข้ามาใหม่ + ค้างรอตรวจกี่เพลง** ไม่ใช่ต้องเดา/ถาม

## ทางแก้ — ระฆัง 🔔 ที่หัวเว็บ (เห็นทุกหน้า)

เหมือนกระดิ่งแจ้งเตือนในแอปทั่วไป:
- **เลขบนระฆัง = ค้างรอตรวจกี่เพลง** (เช่น 🔔③ = 3 เพลง)
- **จุดเขียว = มีเพลง “ใหม่” เพิ่งเข้ามา** (ตั้งแต่ครั้งก่อนที่เปิดดู)
- กดระฆัง → เห็น **รายการเพลงรอตรวจ** → กดเข้าไปตรวจได้เลย

**ต่อยอดของเดิม** — วันนี้มีชิปเล็ก ๆ `📨 n รอตรวจ` อยู่แล้ว งานนี้ยกระดับเป็นระฆัง+badge เต็มตัว (ไม่สร้างใหม่ทับ)

## จุดที่คิดละเอียด — “เลข” กับ “จุดเขียว” ต่างกัน

| | คืออะไร | หายเมื่อไหร่ |
|---|---|---|
| **เลข** | งานจริงที่ยังต้องตรวจ | **ตรวจจริงแล้วเท่านั้น** (แค่เหลือบดู เลขไม่หาย — ป้องกันลืมงาน) |
| **จุดเขียว “ใหม่”** | มีของเพิ่งเข้ามา | **เปิดคิวดูแล้วหาย** (เหมือน iPhone เคลียร์เมื่อเห็นแล้ว) |

## มือถือ vs เดสก์ท็อป (ตาม SOP)

- **เดสก์ท็อป:** กดระฆัง → รายการโผล่ใต้ระฆัง
- **มือถือ (พี่เปา):** กดระฆัง → เปิด **หน้าเต็มจอ** เลือกเพลง → กด “เสร็จ” กลับจุดเดิม

## คนพิการก็ใช้ได้

ระฆังบอกจำนวนด้วยเสียง (“การแจ้งเตือน 3 เพลงรอตรวจ”) และพออัปเดต โปรแกรมอ่านหน้าจออ่านให้เองโดยไม่รบกวน — ตามมาตรฐานสากล (WCAG)

## ทำเป็นกี่เฟส

- **เฟส A:** ระฆัง + เลข (นับสด) + กดเปิดคิว → **พี่เปาเห็นเองว่าค้างกี่เพลง กดไปตรวจ**
- **เฟส B:** จุดเขียว “ใหม่” + จำว่าเห็นแล้ว
- **เฟส C:** อัปเดตสดทันทีที่มีเพลงเข้า (ไม่ต้องรีเฟรช) — รอ SA ดูว่าทำได้แค่ไหน
