## เปิดเป็น GitHub issue

```sh
export GH_TOKEN_AI_COMPANY=<token ของ aim-agent>     # อย่าพิมพ์ค่าลงแชท
bash docs/pm/tickets-2026-10-19/create-github-issues.sh
```

1. ใส่ `DRY_RUN=1` ข้างหน้าเพื่อดูก่อนว่าจะสร้างอะไร
2. สคริปต์เช็กก่อนเสมอว่า token เป็นของบัญชี `aim-agent` ถ้าไม่ใช่จะหยุด ไม่เผลอเปิดใบในนามพี่เอม

⛔ **สคริปต์นี้รันในเซสชันคลาวด์ของ Claude ไม่ได้ผล** — proxy ของเซสชันเขียนทับ
`Authorization` ของทุกคำขอที่ไปหา `api.github.com` ด้วยกุญแจของบัญชีที่พี่เอมเชื่อมไว้
ยิงด้วย token อะไรไปก็ออกมาเป็น `aim-krisada` เสมอ (ทดสอบแล้ว 19 ต.ค. 2569 ยิงด้วย token
มั่ว ๆ ก็ยังได้ `aim-krisada`) **ต้องรันจากเครื่องพี่เอมเอง หรือที่อื่นที่ไม่ผ่าน proxy ตัวนี้**

## เปิดเป็นใบบนอัมกิต

1. เนื้อใบใช้ไฟล์เดียวกันนี้ได้เลย เพราะเขียนตามแบบฟอร์ม WPA อยู่แล้ว
2. อัมกิตต่อจากเซสชันคลาวด์ไม่ได้ ต้องเปิด `git.aimagin.com` ใน Allowed domains ของ environment ก่อน และต้องมี `GITLAB_TOKEN_AI_COMPANY`
3. ท่ายิง REST กับ GraphQL อยู่ในสกิล `aimagin-assign` หัวข้อท่าเทคนิค

## ของที่ยังไม่รู้ ต้องให้พี่เอมเติมก่อนเปิด

1. ชื่อบัญชีผู้รับผิดชอบกับ cc ต้องเป็นคนจริง
2. ที่เก็บใบบนอัมกิต `follow-up/customer` หรือ `follow-up/internal`
3. มีใบรับเรื่องแม่ของรอบนี้อยู่แล้วหรือยัง ถ้ามี ทั้ง 3 ใบต้องเปิดเป็นงานย่อยใต้ใบแม่ ห้ามเปิดคู่ขนาน
4. แม่แบบ WPA ทางการอยู่ที่ https://git.aimagin.com/aimagin/sop/-/tree/main/iso-29110-5-4/templates เปิดจากคลาวด์ไม่ได้ จึงเขียนตามชื่อหัวข้อที่สกิลระบุ ขอให้ทาบกับแม่แบบจริงอีกรอบ
5. หมุดหมายของทั้ง 3 ใบ `2026-10 ครึ่งหลัง`
