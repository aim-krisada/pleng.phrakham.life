## พี่เปาขออะไร

แถบเครื่องมือ (dock) หน้าแก้ไข — พี่เปาอยาก **คุมมันได้เอง** 4 อย่าง: เลือกว่าจะโชว์ปุ่มไหน · ย่อให้เล็กลง (ตอนนี้ใหญ่ไป) · จัดปุ่มเอง · ตั้งทุกอย่างในหน้า settings. **P'Aim เพิ่มข้อสำคัญที่สุด:** ให้ทุกปุ่มมี **"ชื่ออ้างอิง"** ชัด ๆ

**ข่าวดี:** แถบนี้ทำมาดีอยู่แล้ว — เราแค่ **เติมส่วนคุม** ไม่ต้องรื้อ

---

## ⭐ ข้อที่สำคัญที่สุด — "ชื่ออ้างอิง" (แก้ปัญหาการคุยงาน)

P'Aim พูดตรงจุด: *เวลาพี่เปาอยากบอกให้แก้ปุ่มไหน สื่อสารยากมาก ต้อง capture หน้าจอ*

**ทางแก้:** ให้ทุกปุ่มมี **ชื่อไทยเดียว** ที่ —
- โชว์บนปุ่มได้ (เปิด/ปิดสวิตช์) — พี่เปา **เห็นชื่อ = พูดชื่อได้เลย**
- เป็นชื่อที่ **ทั้งทีมใช้เรียก** (พี่เปาพูด "ปุ่มฟังท่อน" → PM/dev รู้ทันทีว่าปุ่มไหน ไม่ต้องส่งรูป)
- เป็น **ชื่อสำหรับคนพิการ** (โปรแกรมอ่านหน้าจออ่านออก) + **ชื่อสำหรับทดสอบ** (ทีม QA) ในตัว

**คิดง่าย ๆ:** เหมือนตั้งชื่อเล่นให้ของทุกชิ้นในห้อง — พอทุกคนเรียกชื่อเดียวกัน ก็ไม่ต้องชี้แล้ว. เราทำ **ตารางชื่อกลาง** (ปุ่ม → ชื่อไทย → รหัสคงที่) ให้ทั้งทีมอ้าง

> นี่ไม่ใช่แค่ feature — เป็น **ภาษากลาง**ของทีมพี่เปา↔PM↔dev · และตรงมาตรฐานสากล (WCAG "ป้ายต้องตรงกับชื่อ") พอดี

---

## อีก 4 ข้อ (ฟันธงแล้ว ไม่ต้องให้ P'Aim เลือกเมนู)

**1. เลือกปุ่มที่โชว์** — หน้าตั้งค่าแบ่ง 2 ฝั่งชัด: *"บนแถบ"* กับ *"เก็บในตั้งค่า"* · ย้ายไปมาได้ · ปุ่มที่ซ่อน **ยังกดใช้ได้** (แค่ไม่กินที่) · มีปุ่ม **↺ คืนค่าเริ่มต้น** — แบบเดียวกับ Photoshop / VS Code

**2. ย่อขนาด** — เลือก **3 ระดับในตั้งค่า: กะทัดรัด / สบาย / ใหญ่** · **ค่าเริ่มต้น = กะทัดรัด (เล็กลงจากตอนนี้)** แต่ยังใหญ่พอกดสบาย (ผ่านมาตรฐานนิ้ว)
> **ทำไมเป็น "เลือกขนาด" ไม่ใช่ "ลากมุมย่อ":** บนมือถือลากมุมเล็งยาก · iPhone (Dynamic Type) กับ Android ก็ให้ "เลือกขนาด" ในตั้งค่า ไม่ใช่ลาก — เราทำตามนั้น

**3. จัดปุ่มเอง** — ใช้ระบบเดิม (ปัก 📌 + เลื่อนขึ้น-ลง ▲▼) · ลาก **ที่จับ** ย้ายทั้งแถบได้ (มีอยู่แล้ว)

**4. ตั้งในหน้า settings** — มี design อยู่แล้ว · งานนี้ทำให้เป็น **ศูนย์คุมเดียว** ครบ

## แก้ครั้งเดียว ได้ 2 เว็บ (พระคำ + เพลง) — SA ยืนยันแล้ว ✅

**ได้จริง** — แถบนี้ (DockKey) **เป็นตัวเดียวกันที่ 2 เว็บใช้ร่วม** อยู่แล้ว (พระคำเอาไปทำแถบ "อ่านออกเสียง") → เราวางระบบชื่ออ้างอิง + เลือกขนาด + สวิตช์ชื่อ ไว้ที่ **ตัวกลางนี้ = แก้ครั้งเดียว 2 เว็บได้วินัยเดียวกัน** (P'Aim คิดถูก)

**ข้อควรรู้:** เพราะเป็นตัวเดียวกัน → ทุกครั้งที่แตะ ต้อง **ทดสอบทั้ง 2 เว็บ** ก่อนปล่อย (กันแถบอ่านออกเสียงของพระคำพัง) · แก้แค่ "ปุ่มของเพลง" (ไม่ใช่ตัวกลาง) → พระคำไม่กระทบ

## ทำเป็นกี่เฟส

- **เฟส A — คุ้มสุด เริ่มได้เลย:** แถบเล็กลง (กะทัดรัด) + สวิตช์แสดงชื่อ + ตารางชื่ออ้างอิง → พี่เปาได้ทั้ง "แถบเล็กลง" และ "เรียกชื่อปุ่มได้" ทันที
- **เฟส B:** หน้าตั้งค่าเลือกปุ่มโชว์/ซ่อน + คืนค่า
- **เฟส C:** เลือกขนาด 3 ระดับ (+ บนคอมลากมุมปรับได้)
- **เฟส D:** ยกขึ้นตัวกลาง → พระคำได้ตาม (รอ SA + P'Aim)
