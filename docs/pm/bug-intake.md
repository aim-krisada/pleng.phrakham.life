# Bug Intake — pleng.phrakham.life

ด่านรับ+กรอง bug (P'Aim → intake channel → PM). Append-only ทีละตัว `BI-NNN`.
รูปประกอบ: `docs/pm/bug-intake-assets/BI-NNN-*.png`.

**เส้นแบ่ง:** intake กรอง+triage · **จ่ายงานแก้ = PM เท่านั้น**.
**จังหวะแจ้ง PM:** รวบเป็นชุด ping ทีเดียว · S1 (prod พัง) = ping ทันที.
**severity:** S1 = prod พัง/ใช้ไม่ได้ · S2 = ใช้งานเสียบางกรณี · S3 = cosmetic/minor.

**วงจรสถานะ (status):**
- 🆕 `new` — รับ+triage แล้ว ยังไม่จ่าย
- 🔧 `dispatched` — PM จ่ายให้ session/round แล้ว (กำลังแก้)
- ☑️ `fixed` — dev แจ้งแก้เสร็จ แต่ intake ยังไม่ verify
- ✅ `verified` — intake เปิดของจริงยืนยันหายแล้ว (ปิด)
- ❌ `wontfix / dup` — ไม่แก้ / ซ้ำกับตัวอื่น

intake อัปเดตสถานะเมื่อ PM/dev รายงานกลับ · **ปิด bug ต้องผ่าน `verified` เท่านั้น** (dev บอก fixed ยังไม่พอ — intake เปิดดูของจริงก่อน).
